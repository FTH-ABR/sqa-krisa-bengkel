Makmal amali / Hands-on lab

Langkah

  1. Makmal A: jalankan koleksi Postman dengan Newman: cd lab/shopfast; npm install; npm run test:api (pelayan mesti berjalan: npm start)
  2. Makmal B: jalankan ujian Playwright: npx playwright install chromium; npx playwright test
  3. Rosakkan aplikasi atau tulis ujian sempadan baharu dan lihat ia gagal dengan jelas
