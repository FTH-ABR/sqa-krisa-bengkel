Konsep mendalam / SQA concept deep dive (15 slaid)

Slaid tambahan dalam deck modul ini yang menerangkan konsep, istilah, piawaian, jenis semakan dan ujian, pengukuran, kawalan dan dokumentasi kualiti di luar KRISA. Slaid bertanda DEEP DIVE.

  1. What is software reliability?
  2. Only a subset of all possible inputs produces erroneous outputs. Each group of users exercises a different region of the input set.
  3. Removing faults is not the same as improving reliability
  4. Every software trouble report (STR) moves through controlled states. Each transition has an owner, so no one closes a bug they raised or fixed alone.
  5. Bug states and who moves the bug
  6. What is software measurement?
  7. The process of product measurement
  8. Control metrics vs predictor metrics
  9. Static vs dynamic product metrics
  10. The ilities cannot be measured directly
  11. Classic code metrics and what they signal
  12. Object-oriented metrics
  13. Defect density: a benchmark with a date on it
  14. Defect clustering: what it means for triage
  15. Defect prevention practices
