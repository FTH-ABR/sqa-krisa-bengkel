Konsep mendalam / SQA concept deep dive (11 slaid)

Slaid tambahan dalam deck modul ini yang menerangkan konsep, istilah, piawaian, jenis semakan dan ujian, pengukuran, kawalan dan dokumentasi kualiti di luar KRISA. Slaid bertanda DEEP DIVE.

  1. SCM makes sure software products are properly identified and every change to them is tracked. All activities revolve around an approved baseline.
  2. SCM activities in practice
  3. SCM vocabulary every SQA engineer uses
  4. Controlling one change from request to release
  5. Software evolution: change is the normal state
  6. Review checklist: maintenance changes
  7. Define the process, develop the product, assess its quality. If quality is not good enough, improve the process; if it is, standardise the process.
  8. Quality improvement: the creative approach
  9. Raytheon's Six Sigma wheel keeps improvement continuous: Visualize, Commit, Prioritize, Characterize, Improve, Achieve, then start again.
  10. Building a defect prevention culture
  11. Early warning: death march projects
